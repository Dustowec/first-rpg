# LLM Game v2.0

**LLM Game v2.0** — это текстовая RPG-игра с элементами рогалика, построенная на основе JSON-конфигов и интегрирующая LLM-NPC для динамических диалогов.

## 📋 Обзор

Проект представляет собой движок для пошаговой текстовой RPG с глубокой проработкой баланса, процедурной генерацией мира и системой диалогов на базе LLM.

### Ключевые особенности

- **Процедурная генерация мира**: регион состоит из 25 узлов (деревня, лагеря, тропы, луга, опушки, руины, чаща, болото, логова), связанных в граф. Каждый регион имеет уникальную карту.
- **Глубокая боевая система**: формулы попадания, урона, критических ударов, уклонения, поглощения брони, уязвимостей и сопротивлений.
- **20 уровней прогрессии**: 5 характеристик (Сила, Ловкость, Выносливость, Интеллект, Мудрость), 9 навыков (3 ветки: бой, магия, выживание), система перков на 3/6/10 уровнях.
- **LLM-NPC**: динамические диалоги с NPC через OpenAI-совместимый API (Qwen3-4B-Instruct) с fallback на статические реплики.
- **Экономика и крафт**: алхимия, кулинария, ремонт экипировки, система прочности.
- **Голод и время**: цикл дня из 20 ходов, 2 приёма пищи, естественная регенерация HP/MP.
- **Магия**: 3 школы (pyromancy, restoration, hexes), 9 заклинаний с разной механикой.
- **Расходники**: зелья, эликсиры, масла, бомбы — с балансировкой под прогрессию HP/MP.
- **Монстры**: 5 тиров, матрица уязвимостей (beast, undead, humanoid, construct, plant/insect), лут-таблицы.

## 🏗️ Архитектура

Проект построен на принципе **data-driven**: вся логика отделена от данных. JSON-файлы содержат описания предметов, монстров, рецептов, заклинаний, навыков и NPC. Ядро игры — чистые функции `state + command -> new state + events`.

### Структура данных

```
data/
├── armor/          # Броня (cloth, leather, plate)
├── biomes/         # Биомы/типы локаций
├── consumables/    # Расходники (зелья, эликсиры, масла, бомбы)
├── food/           # Еда (подножная, готовая, консервы)
├── materials/      # Материалы (кости, волчьи глаза)
├── monsters/       # Монстры (5 тиров, 24+ вида)
├── npcs/           # NPC (профили, реплики, торги)
├── recipes/        # Рецепты крафта (алхимия, кузнец)
└── weapons/        # Оружие (blunt, spear, sword)
```

### Основные компоненты

| Компонент | Описание                                                            |
|-----------|---------------------------------------------------------------------|
| `player`  | Состояние персонажа: HP/MP, атрибуты, навыки, экипировка, инвентарь |

## 🎮 Геймплей

### Цикл дня

1. **Утро (шаг 1–6)**: нужно поесть до шага 7, иначе смерть от голода.
2. **День (шаги 2–9)**: исследование, бой, поиск, крафт.
3. **Вечер (шаг 10–16)**: ужин до шага 17.
4. **Ночь**: естественная регенерация HP/MP.

### Бой

- Попадание: `random(0, 100) <= hitChance`, где `hitChance = clamp(50 + skill*3 + agi*2 - evasion, 15, 80)`.
- Урон: `rawDamage = random(min, max) * (1 + skill*0.05) + (stat-1)*0.5`, затем поглощение бронёй: `finalDamage = typedDamage * (10 / (10 + defense))`.
- Крит: 5% базово, до 10% с перками, множитель ×1.5 (×2.0 с грандмастером).
- Отступление: 50% шанс, монстр остаётся в локации.

### Характеристики

| Атрибут                         | Влияние                       |
|---------------------------------|-------------------------------|
| **Сила (strength)**             | +0.5 урона за пункт           |
| **Ловкость (agility)**          | +2% меткость, +1.5% уклонение |
| **Выносливость (constitution)** | +2 MaxHP за пункт             |
| **Интеллект (intelligence)**    | +0.75 магия, +1.5% поиск      |
| **Мудрость (wisdom)**           | +2 MaxMP за пункт             |

### Навыки (9 штук, шкала 0–10)

**Бой:**
- `melee_heavy` — тяжёлое оружие (дубины, мечи)
- `melee_light` — лёгкое/древковое (копья)
- `armor_mastery` — броня и защита

**Магия:**
- `pyromancy` — стихии (fire, ice)
- `restoration` — лечение, барьеры
- `hexes` — яды, проклятия, вампиризм

**Выживание:**
- `alchemy` — зелья и эликсиры
- `crafting` — ремонт и заточка
- `scavenging` — поиск и лут

## 🔧 Технологии

- **Ядро**: Python (чистые функции, JSON-серилизация)
- **Модель**: Qwen3-4B-Instruct (Q4_K_M, ~2.5 ГБ VRAM)
- **API**: OpenAI Chat Completions (`/v1/chat/completions`)
- **Параметры**: `temperature: 0.6`, `max_tokens: 250`
- **Прототип**: CLI (терминальный интерфейс)
- **Планируемый порт**: Godot 4 (GDScript)

## 🚀 Быстрый старт

### Требования

- Python 3.10+
- Локальная LLM-сервер (llama.cpp / Ollama / LM Studio) с моделью `Qwen3-4B-Instruct-Q4_K_M`
- Или отключение LLM в конфиге (`meta.llm.enabled: false`)

### Запуск

```bash
# 1. Клонируйте репозиторий
git clone <repo-url>
cd LLM_game_v_2_0

# 2. Создайте виртуальное окружение
python -m venv venv
venv\Scripts\activate  # Windows

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Запустите LLM-сервер (опционально)
# Ollama:
ollama run qwen3:4b
ollama serve

# Или LM Studio / llama.cpp

# 5. Запустите игру
python main.py
```

### Первый запуск

При первом запуске:
1. Если `state_session.json` отсутствует — создаётся новая игра из `state_template.json`.
2. Карта генерируется с seed `20260101` (эталонная карта: 25 узлов, деревня на старте).
3. Игрок начинает с: HP 10, MP 2, золото 15, дубина, рваная ткань.

## 🗺️ Карта мира

Регион состоит из **25 узлов** в 6 слоях глубины:

| Глубина | Узлов       | Опасность | Тиры монстров |
|---------|-------------|-----------|---------------|
| 0       | 1 (деревня) | 0         |      —        |
| 1–2     | 8           | Низкая    | Tier 1        |
| 3–4     | 10          | Средняя   | Tier 2        |
| 5–6     | 7           | Высокая   | Tier 3        |
| Логово  | 1           | Босс      | Tier 4–5      |

## ⚙️ Конфигурация

Основные настройки в `state_session.json` (раздел `meta`):

```json
{
  "meta": {
    "seed": 20260101,
    "region": 1,
    "llm": {
      "enabled": true,
      "endpoint": "http://127.0.0.1:8080/v1/chat/completions",
      "model": "Qwen3-4B-Instruct-Q4_K_M",
      "timeoutSec": 15
    }
  }
}
```
